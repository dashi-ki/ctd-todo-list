# To-Do App

## Description
This is a simple to-do app built as part of a React course. It allows users to add, view, and manage tasks. 

## API
This app connects to a hosted backend API for authentication and task management:
```
https://ctd-learns-node-l42tx.ondigitalocean.app
```

## Installation
1. Clone the repository:
   git clone https://github.com/dashi-ki/ctd-todo-list.git

2. Install dependencies:
   npm install

3. Set up environment variables by creating a `.env` file in the root of the project:
   ```
   VITE_TARGET=https://ctd-learns-node-l42tx.ondigitalocean.app
   ```

## Run the Development Server
Start the app locally by running:
npm run dev

Then open your browser and go to:
http://localhost:3001
